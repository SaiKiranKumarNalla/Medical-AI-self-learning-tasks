# Medical AI self-learning tasks

Guided, AI-assisted learning projects using public medical datasets. Implementation is AI-assisted; the learner directs questions and interpretation. These are educational studies, not clinically validated products.

- [PneumoniaMNIST classification tutorial](pneumoniamnist/README.md): small-image ResNet, loss functions, residual ablation and reviewed error analysis.

Private conversations, datasets and checkpoints are not included.
