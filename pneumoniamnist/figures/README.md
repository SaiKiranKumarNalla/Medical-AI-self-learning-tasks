# Figure provenance

gradcam_error_analysis.png is regenerated by audit_results.py from the saved baseline checkpoint and official test samples. Its category labels are checked against predictions.

All other figures are historical learning artifacts. Their generating code is not fully preserved here; they are not independent verification of reported metrics. In particular, use results/verified_metrics.json instead of numbers embedded in old comparison graphics. Architecture graphics must be interpreted against the actual Python model definitions. No figure establishes a clinical anatomical diagnosis.
